Blood Analysis for Diabetes Prediction by Disha Chaudhary focuses on early diagnosis using machine learning on blood test data (LMCH dataset: HbA1c, BMI, glucose, lipids). Using ANOVA feature selection and hyperparameter tuning, it compares Random Forest, MLP, and SVM across 5-fold cross-validation, with Random Forest yielding top accuracy.
